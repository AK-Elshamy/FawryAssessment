# Quantum Radar Traffic Violation System

This project is my solution for the **Fawry Quantum Internship Challenge**.

The system simulates a traffic radar that:
- Processes vehicle observations
- Checks traffic rules
- Detects violations
- Generates fines
- Provides statistics about fines and violated rules

## Technologies
- Java
- Object-Oriented Programming (OOP)
- SOLID Principles
